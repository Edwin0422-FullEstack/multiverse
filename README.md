## 🔥 Lo Nuevo: Inmersión Total

Esta no es solo otra aplicación de personajes. Hemos elevado la experiencia a un nivel interdimensional:

- **🛸 Interfaz "Portal Gun"**: Un diseño dinámico que utiliza una paleta de colores *Neon Green* y *Cosmic Purple*, emulando la energía de los portales de Rick.
- **🎴 Flip Cards 3D**: Las tarjetas de personajes ahora cuentan con un sistema de rotación 3D. Haz clic para voltearlas y revelar una ficha técnica detallada del espécimen.
- **⌨️ Terminal Typewriter**: Encabezados con efecto de escritura en tiempo real utilizando la fuente futurista *Orbitron*.
- **🧪 Efecto Ácido Dinámico**: Títulos animados con degradados fluidos y burbujas radiactivas que cobran vida en tu pantalla.
- **✨ Scroll Custom Neón**: Olvídate de las barras de scroll genéricas. Hemos implementado un scrollbar personalizado con brillo neón que solo aparece donde lo necesitas.

## 🚀 Despegue Inmediato

¿Listo para saltar a otra dimensión? Sigue estos pasos:

1. **Clonar e instalar dependencias**:
    ```bash
    pnpm install
    ```
2. **Sincronizar el Multiverso (Dev Server)**:
    ```bash
    pnpm run dev
    ```
3. **Acceder al Portal**: Abre `http://localhost:5173` en tu navegador.

## 🧠 Excelencia en Ingeniería (Clean Architecture)

El proyecto no solo brilla por fuera, su núcleo es una obra maestra de la ingeniería de software:

- 📂 **Capa Core (Domain)**: Modelos de datos e interfaces puras. El contrato inmutable del multiverso.
- 📂 **Capa Application**: Orquestación de lógica mediante Custom Hooks avanzados (`useCharacters`, `useTypewriter`, `useFavorites`).
- 📂 **Capa Infrastructure**: Implementación de repositorios y clientes API con abstracción total.
- 📂 **Capa UI (Atomic Design)**: Componentes modulares, reutilizables y altamente estilizados.

### 🛠️ Arsenal Tecnológico

- **React Query (V5)**: Gestión de estado asíncrono con caché inteligente y persistencia en memoria de 0ms al navegar.
- **React Virtual (TanStack)**: Virtualización de listas masivas. Renderiza miles de personajes con una fluidez de 60fps constantes.
- **Framer Motion / CSS 3D**: Animaciones complejas de volteo y transición que no afectan el rendimiento.
- **Responsive Pro**: Adaptabilidad matemática total desde dispositivos móviles hasta pantallas ultra-wide.
